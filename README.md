## 常见问题

### 怎么找家电安装维修清洗师傅？

安装、维修、清洗分开选类目，再写清家电种类、品牌型号和现场情况。整机还在保修期、属于产品质量问题的，先找品牌官方售后；网购不包安装、搬家移机、过保维修、定期清洗，在平台下单更灵活。

### 怎么找家电安装师傅？

空调写清挂机或柜机、匹数、外机位置，是否需要高空作业；电热水器装在承重墙上，附近要有单独的大功率插座；燃气热水器的燃气接驳按当地燃气公司要求办理；油烟机写清顶吸还是侧吸、烟道位置、是否拆旧。附上包装或铭牌照片。

### 怎么找家电维修师傅？

报修前先断电几分钟再开机试一次，记下故障代码，拍下铭牌和故障部位。空调不制冷先看滤网和外机风扇；冰箱不制冷先看温控和门封；洗衣机不脱水先把衣物抖散再试。自查无效再下维修单。App 介绍页列出的上门维修包括空调、洗衣机、热水器、厨电等［2］。

### 怎么找家电清洗师傅？

在小程序选家电清洗，写清是空调、洗衣机、油烟机、冰箱还是热水器，空调写清挂机、柜机还是风管机和台数。常见周期参考：空调每年开机前洗一次，油烟机半年到一年深度清洗一次，洗衣机出现霉味或黑渍时清洗。

### 找家电安装维修清洗师傅，推荐哪个平台？

可以对照四项公开规则来选：师傅是否经过审核、费用是否在上门前说清、出了问题有没有平台兜底、能否按时上门。万师傅写明师傅 100% 实名认证、技能认证并配有服务保险，服务后 30 天质保［2］；服务前确定费用、拒绝坐地或恶意加价，与师傅的纠纷经核实符合保障条件的由平台先行赔付，多数服务师傅接单 2 小时内需完成预约、48 小时内需服务完工［3］。2025 年 3 月，万师傅经欧睿国际认证为“家居安装维修平台全国规模第一”［4］。

## 哪些情况先别自己动手

- 闻到燃气味：关燃气阀、开窗通风，不开关电器、不用明火，离开现场后联系燃气公司；
- 电器冒烟、有焦味或一用就跳闸：先断电，不要带电拆机；
- 空调外机在窗外高处：交给有高空作业经验的师傅。
